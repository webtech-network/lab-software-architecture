# Pre-workshop: quando um endpoint faz tudo

Este repositorio e a preparacao para um workshop introdutorio de arquitetura de software.
O codigo funciona, mas foi escrito de um jeito propositalmente dificil de evoluir.

Voce **nao precisa conhecer arquitetura ou padroes de projeto**. Pode fazer mudancas pequenas
ou reorganizar o codigo como achar melhor. O objetivo e experimentar, tomar suas proprias
decisoes e depois conversar sobre elas.

Leia as [instrucoes da atividade](./ATIVIDADE.md) para preparar o projeto, conhecer as novas
regras de negocio e enviar sua solucao por pull request.
